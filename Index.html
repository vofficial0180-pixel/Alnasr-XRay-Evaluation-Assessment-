Data Sync Between Devices

This is a self-contained offline file with no server — each device (laptop, phone, tablet) keeps its own separate copy of the data. To bring one staff member's history, the image library, or session logs from one device to another: Export here, send the downloaded file to the other device (email, WhatsApp, USB, shared drive — anything works, it's just a small JSON file), then open this app on that device and Import it. Import merges — it adds anything new without deleting existing records.

Host It Centrally (optional, for true real-time sync)

If every device needs to see the same live data automatically, this folder (index.html + images) can be placed on any internal web server, shared network drive, or basic static hosting your IT team controls. The app itself needs no installation or database — but genuine real-time sync across many devices does require a small shared backend, which is outside what a static offline file can do on its own. Export/Import above is the reliable offline-safe way to move data until/unless that's set up.
